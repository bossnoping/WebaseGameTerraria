# WebaseGameTerraria

Fan-made **Terraria: Boss Rush** — a 3D web-based strategic cooperative card battle
prototype built for a classroom presentation.

Fight the Eye of Cthulhu under an endless Blood Moon: build a hand of weapon, armor,
potion, and spell cards, and defend the NPC village turn by turn.

See [`AGENTS.md`](./AGENTS.md) for the architecture and development commands once the
game lands on `main`.
